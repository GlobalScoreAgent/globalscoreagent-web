# Global Score Agent (GSA) Pricing

Global Score Agent offers a flexible and transparent pricing structure designed for both human users who want deep visual analysis and AI agents that need automated, high-volume evaluations.

## Dashboard Plans

| Plan                        | Monthly Price | Annual Price | Savings | What’s Included |
|----------------------------|---------------|--------------|---------|-----------------|
| **Free Trial**             | $0            | $0           | -       | Full Dashboard access for 5 days + 20 API credits |
| **Dashboard Solo Monthly** | $9            | -            | -       | Unlimited Dashboard access |
| **Dashboard Pro Monthly**  | $15           | -            | -       | Unlimited Dashboard access + 130 API credits per month |
| **Dashboard Solo Annual**  | -             | $99          | 8%      | Unlimited Dashboard access |
| **Dashboard Pro Annual**   | -             | $159         | 12%     | Unlimited Dashboard access + 130 API credits per month |

### Plan Notes:
- The **Free Trial** lasts **5 days**.
- **Annual** plans offer a discount compared to monthly billing.
- API credits included in **Pro** plans renew monthly.

## API Pricing (Credits)

Global Score Agent offers two ways to access the API:

- **Direct Payment** (Pay Per Use, without buying credits in advance).
- **Credit Plans** (Starter, Growth, Pro, and Enterprise), where the price per query is lower the more credits you purchase in advance.

### API Pricing Table

| Report Type                                  | Direct Price (Pay Per Use) | Starter ($0.0833/credit) | Growth ($0.0781/credit) | Pro ($0.0714/credit) | Enterprise ($0.0667/credit) |
|----------------------------------------------|----------------------------|--------------------------|-------------------------|----------------------|-----------------------------|
| **Basic** (HUMI + WAMI + Warnings)           | $0.20                      | $0.17 (2 credits)        | $0.16 (2 credits)       | $0.14 (2 credits)    | $0.13 (2 credits)           |
| **With Analysis** (Full HUMI or WAMI)        | $0.45                      | $0.42 (5 credits)        | $0.39 (5 credits)       | $0.36 (5 credits)    | $0.33 (5 credits)           |
| **GSA Index Complete**                       | $0.85                      | $0.83 (10 credits)       | $0.78 (10 credits)      | $0.71 (10 credits)   | $0.67 (10 credits)          |

### API Pricing Notes:

- The prices under **Starter, Growth, Pro, and Enterprise** apply when you purchase credits in advance.
- The higher the credit package you buy, the lower the cost per query.
- The **Enterprise** plan offers the best price per credit for high-volume users or AI agents.

## Credit Expiration

- Credits obtained through the **Free Trial** or **promotional codes** **do not expire**. They remain linked to your profile and can be used at any time.
- Monthly credits included in **Pro** Dashboard plans are valid for **30 days** and **are not cumulative**. If unused during the billing period, they are lost at the end of the month.

## Free Trial Policy

After the **5-day free trial** ends, query and analysis features in the Dashboard become **locked**. However, you will still have access to the Dashboard to:

- Subscribe to a paid plan, or
- Create an API Key and use any available API credits (if you have any).

## Plan Changes, Cancellations, and Refunds

To perform any of the following actions, you must submit a ticket through the **Feedbacks** option available in the Dashboard menu:

- Subscription cancellation
- Plan change (upgrade or downgrade)
- Refund request
