# Agents Directory

The **Agents Directory** page allows you to search, filter, and explore all registered agents on the platform in a visual and efficient way.

## How the Agents Directory Works

This page displays agents as cards, showing key information such as the agent’s name, chain, image, and HUMI score.

The list of agents is **not loaded all at once**. Initially, between **10 and 20 agents** are loaded. As you scroll down the page, the next groups of agents are automatically loaded (lazy loading / infinite scroll). This keeps the page fast and responsive even when there are many registered agents.

## Search and Filter Options

At the top of the page, you have several ways to search for agents:

### Text Search

You can search for agents using the following criteria:

| Search Type            | Where it searches                                                              | When to use it |
|------------------------|--------------------------------------------------------------------------------|----------------|
| **General**            | Searches across name, description, capabilities, skills, and services          | Recommended for broad searches |
| **Name**               | Only in the agent’s name                                                       | When you know the name (exact or partial) |
| **Wallet**             | In the agent’s wallet address                                                  | To find agents belonging to a specific wallet |
| **Wallet Owner**       | In the wallet that owns the agent                                              | To see all agents owned by a specific wallet |
| **Agent Identifier**   | In the agent’s ID on the chain                                                 | To search for an agent by its on-chain ID |

### Advanced Filters

In addition to text search, you can use **Advanced Filters** to refine your results. These filters include categories such as:

- OASF Domains (thematic areas of the agent)
- Technical tags and categories
- Specific skills
- Supported services
- Compatibility with protocols (x402, MCP, A2A, etc.)
- And many other advanced options

You can combine multiple filters at the same time to perform very specific searches.

**Tip**: Start with a **General** search and then apply advanced filters if you need more precision.

## Agent Cards

Each agent is displayed as a card containing the following information:

- Representative image of the agent
- Agent name
- Chain where it is registered (e.g., Base, Arbitrum, etc.)
- **HUMI** score
- "STAR" badge (if applicable)

### Clicking on a Card

When you click on any card, **the card flips** and displays a **basic summary** of the agent, including:

- Main information (name, chain, short description)
- Current HUMI score
- Relevant agent data

![Agent Basic Summary (Card Flip)](../../images/dashboard/agent-card-flip.png)

If you want to see the **full detailed information** of the agent (complete HUMI, WAMI, feedback, warnings, history, etc.), click the **+** button on the side of the card.

---

## Usage Tips

- Always start with a **General** search if you are not looking for something very specific.
- Use **Advanced Filters** when you need to find agents with specific technical characteristics.
- Agents with the **STAR** badge are usually highlighted or high-quality agents.
- You can sort the results by **HUMI Index Score** (highest to lowest) to see the best-rated agents first.
- The list loads progressively as you scroll down, so there is no need to wait for all agents to load at once.
