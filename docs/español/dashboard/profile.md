# Perfil

La página **Perfil** permite gestionar la información de tu cuenta, preferencias del Dashboard y tus agentes favoritos.

## 1. Cuenta (Account)

En esta sección se muestra la información general de tu cuenta:

- **Cuenta OAuth** (Google o GitHub): El nombre y avatar se gestionan automáticamente desde tu proveedor de autenticación.
- **Nombre para mostrar** (Display name): Puedes editar el nombre que se mostrará en la plataforma.
- **URL del Avatar**: Puedes personalizar la URL de tu imagen de perfil.
- **Correo de contacto** (opcional): Puedes agregar un correo electrónico de contacto.

![Sección de Cuenta](../../images/dashboard/profile-account.png)

---

## 2. Redimir Código (Redeem Code)

Esta sección te permite canjear códigos promocionales o de acceso.

Simplemente ingresa el código en el campo de texto y haz clic en el botón **Redimir**.

![Redimir Código](../../images/dashboard/profile-redeem-code.png)

---

## 3. Preferencias (Preferences)

En esta sección puedes configurar tus preferencias personales del Dashboard:

- **Idioma**: Puedes elegir entre **Español** o **English**.
- **Tema**: Puedes seleccionar entre **Oscuro** (Dark) o **Claro** (Light).

Los cambios se aplican de forma inmediata.

![Preferencias](../../images/dashboard/profile-preferences.png)

---

## 4. Agentes Favoritos (Favorite Agents)

Aquí se muestra la lista de agentes que has marcado como favoritos.

En esta sección puedes:

- Ver la lista de tus agentes favoritos.
- Hacer clic en un agente para acceder rápidamente a su información.
- Eliminar agentes de la lista de favoritos usando el botón **Remove**.

![Agentes Favoritos](../../images/dashboard/profile-favorite-agents.png)

---

## Consejos de Uso

- Mantén actualizado tu **Nombre para mostrar** y **Avatar** para una mejor identificación dentro de la plataforma.
- Usa la sección de **Agentes Favoritos** para tener acceso rápido a los agentes que más utilizas.
- Cambia el **Idioma** y el **Tema** según tu preferencia para una experiencia más cómoda.
- La sección de **Redimir Código** es útil cuando recibes códigos promocionales o de acceso especial.
