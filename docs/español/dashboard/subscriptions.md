# Suscripciones

La página **Suscripciones** permite gestionar tu plan actual, ver el historial de suscripciones y explorar los planes disponibles para actualizar.

## 1. Suscripción Activa

En esta sección se muestra la información de tu suscripción actual, incluyendo:

- Tipo de plan activo
- Fecha de inicio de la suscripción
- Fecha de finalización (si aplica)
- Estado de la suscripción

Aquí podrás ver de forma clara qué plan tienes contratado en este momento y hasta cuándo está vigente.

---

## 2. Historial de Suscripciones

Esta sección muestra el historial completo de suscripciones asociadas a tu perfil.

Podrás consultar:

- Planes que has tenido anteriormente
- Fechas de inicio y fin de cada suscripción
- Cambios de plan realizados

Es útil para llevar un registro de tu historial de uso de la plataforma.

---

## 3. Planes Disponibles

En esta sección se muestran los planes disponibles para contratar.

- Si tienes una suscripción **Free**, podrás ver y contratar cualquiera de los planes pagos disponibles.
- Si ya tienes un plan pago, esta sección puede mostrar opciones de upgrade o información adicional según tu plan actual.

Aquí podrás comparar los diferentes planes y elegir el que mejor se adapte a tus necesidades.

---

## 4. Más Detalles

Esta sección contiene información adicional sobre:

- Políticas de pagos y facturación
- Cómo funcionan los créditos de API
- Renovación automática de suscripciones
- Cancelación de planes
- Diferencias entre los planes disponibles

Es recomendable revisar esta sección si tienes dudas sobre el funcionamiento de las suscripciones o los créditos de API.

---

## Consejos de Uso

- Revisa regularmente la sección de **Suscripción Activa** para conocer la fecha de vencimiento de tu plan.
- Consulta el **Historial de Suscripciones** si necesitas llevar un registro de los cambios de plan que has realizado.
- Si tienes una cuenta Free, visita la sección de **Planes Disponibles** para evaluar una posible actualización.
- La sección de **Más Detalles** es útil para resolver dudas sobre pagos, créditos de API y condiciones de servicio.
